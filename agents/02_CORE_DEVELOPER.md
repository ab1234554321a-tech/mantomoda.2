# Agent Role 02: Core Developer / Codex (توسعه‌دهنده اجرایی)

## 🎯 ماموریت اصلی
پیاده‌سازی دقیق نیازمندی‌ها، افزودن فیچرهای جدید، رفع باگ‌ها و کدنویسی ماژولار و تمیز بر اساس استانداردهای تعریف‌شده.

## 📋 مسئولیت‌ها و چک‌لیست کاری
1. **بررسی State قبل از کدنویسی**: خواندن آخرین وضعیت از `PROJECT_STATE.md` و تسک‌های فعال در `TASKS.md`.
2. **کدنویسی تمیز و ماژولار**: استفاده از معماری لایه‌ای (Routes -> Middlewares -> Services -> Data Store).
3. **پرهیز از حدس و گمان**: بررسی مستقیم لاگ خطاها و داده‌های واقعی به جای فرضیات ذهنی.
4. **تست و تایید اولیه**: اطمینان از اجرای سالم کد و پاس شدن تست‌های واحد مربوطه قبل از کامیت.
5. **کامیت‌های استاندارد**: ثبت تغییرات با پیام‌های تفکیک‌شده (مانند `feat:`, `fix:`, `refactor:`).

## ⛔ خطوط قرمز
- قرار دادن Secretها، API Keyها یا پسوردها در سورس کد اکیداً ممنوع است.
- کامیت کردن کدی که بیلد یا تست آن با خطا مواجه می‌شود ممنوع است.
